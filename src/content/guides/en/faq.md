## Kicked from / can't join a server?

Usually the **wrong CSP version** or a **missing required mod**. Follow Content Manager's prompt to switch CSP version and install the required cars / tracks.

## Installed a mod but it doesn't show?

- Make sure it installed correctly (dragging into CM is the most reliable).
- Some cars / tracks **require CSP** or official DLC — add those first.
- A wrong folder structure inside the archive can break detection; re-organise as "one folder per mod".

## Poor graphics / low FPS?

- Adjust quality in `Content Manager → Settings`; CSP + Sol / PURE look great but cost more performance.
- Try lowering shadow / reflection levels first for more frames.

## Still stuck?

Ask in the QQ group or community discussions linked on the [about page](/en/about) — good answers get folded back into these guides.
