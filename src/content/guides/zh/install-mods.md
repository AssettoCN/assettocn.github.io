## 先认识根目录

装 mod 就是往**游戏根目录**里放文件。上一关记下的那个目录(`...\steamapps\common\assettocorsa`),里面这几个文件夹和装 mod 最相关:

| 文件夹 | 放什么 |
| --- | --- |
| `content\cars\` | 车辆 |
| `content\tracks\` | 赛道 |
| `apps\lua\`、`apps\python\` | 应用类 mod(按脚本类型分) |
| `extension\` | CSP 相关内容,常见 `config-ext`(Pure 配置、滤镜脚本设置) |
| `system\cfg\` | 后处理滤镜文件与脚本 |

> 建议在文件资源管理器里右键根目录 → **固定到快速访问**,后面会经常来。

## 手动安装(推荐)

**手动装比拖进 CM 可靠。** 通过 Content Manager 安装有可能放错位置或损坏 mod;如果某个 mod 用 CM 装完出了问题,按下面的步骤重装一遍,会覆盖掉之前的错误安装。

关键是看清压缩包**从哪一层开始打包**:

- 压缩包里**已经带着** `content\tracks\某赛道\` 这样的完整路径 → 直接把内容拖进**根目录**,合并覆盖。
- 压缩包里**只有** `某赛道\` 这一层 → 那就自己放进 `content\tracks\` 里。

车辆同理。**一个 mod 一个文件夹**,别把多个 mod 的文件混在一起。

## 拖进 Content Manager

省事的做法:直接把压缩包拖进 CM 窗口,CM 会尝试识别并安装。适合结构规范的 mod,装完在 CM 的车库 / 赛道列表里就能看到。

但如前所述,遇到不显示、贴图错乱、进不去这类问题时,**改回手动安装**。

## 去哪找 mod

- 看本站的 [作者页](/authors) —— 我们收录国内 modder,点进作者主页就是他们的发布渠道(B站 / 爱发电等)。
- 我们**不直接托管 mod**,只把你导向作者本人的发布页,确保你拿到的是正版、最新版。

## 装了不显示?

按这个顺序排查:

1. **文件夹层级放错了** —— 最常见,回去核对上面那条。
2. **依赖 CSP** —— 很多新 mod 要求 CSP,甚至要求某个版本。
3. **依赖官方 DLC** —— 有些 mod 会复用 DLC 的车或赛道资源。
4. 认准来源,别装来路不明的文件。
