## 最省事:拖进 Content Manager

大多数 mod 是一个压缩包(`.zip` / `.rar` / `.7z`)。**直接把压缩包拖进 Content Manager 窗口**,CM 会识别并装到正确位置。装完在 CM 的车库 / 赛道列表里就能看到。

## 手动安装

需要手动时:车辆放到 `assettocorsa\content\cars\`,赛道放到 `assettocorsa\content\tracks\`,**一个 mod 一个文件夹**。

## 去哪找 mod

- 看本站的 [作者页](/authors) —— 我们收录国内 modder,点进作者主页就是他们的发布渠道(B站 / 爱发电等)。
- 我们**不直接托管 mod**,只把你导向作者本人的发布页,确保你拿到的是正版、最新版。

## 注意

- 认准来源,别装来路不明的文件。
- 有些车 / 图**依赖 CSP** 或特定 DLC,装了不显示先检查这些。
