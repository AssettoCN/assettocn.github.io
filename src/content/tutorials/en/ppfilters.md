A post-processing filter (PPFilter) is a config file (`.ini`) that controls the game's final image in real time. It covers everything from colour grading and contrast to advanced effects like bloom, lens flare and depth of field. It's the main tool for getting a particular visual style in Assetto Corsa.

## Prerequisites

- Something that can extract `.zip` archives.
- The latest [Content Manager](/start/content-manager-csp), installed and configured.
- The latest [CSP](/start/content-manager-csp), installed and working.
- The latest [Pure](https://www.patreon.com/c/peterboese/posts) — recommended for best compatibility.

## Install manually **(required)**

1. Download the filter's `.zip`.
2. Extract its contents into your [root folder](/tutorials/root-folder), allowing it to overwrite when prompted.
3. Restart Content Manager so the changes take effect.

<aside class="cx cx--info">

<span class="cx__t">Best practice</span>

Always restart CM after installing a new filter. Otherwise its scripts and settings may not apply correctly.

</aside>
